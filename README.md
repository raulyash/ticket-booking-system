# Ticket Booking System

A multithreaded Spring Boot application demonstrating:

- Race conditions
- Thread safety
- Seat-level locking
- ReentrantLock
- Concurrent booking simulation
- ExecutorService
- Fine-grained locking

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

## Features

- Book tickets
- Prevent double booking
- Simulate concurrent users
- Seat locking
- Booking history

## Future Enhancements
